# Calculator Web Application

## OASIS INFOBYTE Internship — Level 2 Task 1

### Project Objective

Build a fully functional browser-based calculator capable of performing basic arithmetic operations using a user-friendly button interface.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Decimal calculations
- Clear button
- Backspace button
- Previous expression and result display
- Operator chaining
- Division-by-zero error handling
- Responsive user interface

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript

## Key Implementation Details

- CSS Grid is used for the calculator button layout.
- JavaScript event listeners are used for button interactions.
- The calculator does not use `eval()`.
- Division by zero is handled with an error message.

## How to Run

1. Download or clone the repository.
2. Open the `WebDev-L2-Calculator` folder.
3. Open `index.html` in a web browser.
4. Start using the calculator.
